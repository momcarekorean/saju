# 진태양시 만세력

생년월일과 태어난 시각으로 사주 여덟 글자를 계산하고,
2025년 인기 이름 중 사주에 맞는 이름과 한자를 추천합니다.

- 절기·진태양시(경도+균시차)·표준자오선 이력·서머타임 보정
- 십신 / 오행 분포 / 작명 방향(부족 보충 · 억부)
- 인명용 한자 1,136항목 (원획·부수 자원오행·이름 사용 빈도)
- 2025년 출생신고 상위 이름 여아 481 · 남아 471

의존성 없는 단일 HTML 파일입니다. `index.html` 하나로 동작합니다.
